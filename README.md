# GeoSolver

GeoSolver — клиентский редактор геометрических чертежей и численный решатель
систем ограничений. Построение, история действий, разбор формул и поиск решения
выполняются локально в браузере.

**Текущая версия: 0.1.0**

## Возможности

- Точки, отрезки, прямые и лучи.
- Окружности, эллипсы, малые и большие секторы (в том числе с углом больше
  180°), а также круговые сегменты.
- Точки, прикреплённые к отрезку, прямой, лучу, окружности, эллипсу либо
  границе сектора, кругового сегмента и многоугольника.
- Произвольные и правильные многоугольники.
- Произвольные, прямоугольные, равнобедренные и равносторонние треугольники.
- Квадраты, прямоугольники, параллелограммы, трапеции и ромбы с готовыми
  ограничениями.
- Выделение и перемещение группы объектов.
- Измерение длин, углов и площадей по существующим точкам без добавления их в
  цели; перетаскивание пустого поля перемещает камеру.
- Ограничения длин, углов, площадей, координат и взаимного расположения,
  включая точки пересечения `H = EG ∩ DF`, `line(EG)`, `ray(EG)` и
  `circle(OA)`.
- Пользовательские переменные и формулы, например `a = AB`, `b = 2*a`,
  `a + b = c`.
- Цепочки равенств: `AB = BC = CD`, с автоматическими одинаковыми штрихами
  на равных сторонах и частях объектов вроде `D ∈ AC`, `AD = DC`.
- Численный поиск с настраиваемым допуском `ε` (`1e-6` по умолчанию) и показом
  ближайшего решения.
- Отмена и повтор действий, переименование точек и непрерывное
  переупорядочивание строк мышью, пальцем или `Alt+↑/↓`; обычные `↑/↓`
  переключают активную строку.
- Адаптивный интерфейс для портретной и альбомной ориентации, с
  полноширинными мобильными разделами и прокручиваемой панелью инструментов.
- Светлая и тёмная темы с сохранением выбора в браузере.
- Русский и английский интерфейс с сохранением выбора в браузере.
- Встроенная справка на двух языках, открываемая кнопкой, `F1` или `?`.

## Быстрый старт

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

После запуска откройте адрес, показанный в терминале. Для первой задачи:

1. Постройте точки и фигуры.
2. Добавьте условия, например `AB = 5` и `∠ABC = 90°`.
3. Добавьте цель, например `BC`. Необязательный суффикс `= ?` добавится
   автоматически.
4. Нажмите «Решить систему» или `Ctrl+Enter`.

## Синтаксис

Примеры ограничений:

```text
AB = 5
∠ABC = ∠BCA + 10°
S(ABCD) = 12
A = (2, -1)
D ∈ line(AB)
AB ⟂ CD
AB ∩ CD = ∅
H = EG ∩ DF
H = line(EG) ∩ circle(OA)
distinct(ABCD)
AB != BC
0 < AB <= 10
x(A) >= 0
```

Специальные символы можно вводить командами:

```text
\angle  → ∠
\cap    → ∩
\empty  → ∅
\deg    → °
\in     → ∈
\perp   → ⟂
\neq    → ≠
\le     → ≤
\ge     → ≥
```

Полный список команд, инструментов и примеров находится во встроенной справке.

## Команды проекта

| Команда | Назначение |
| --- | --- |
| `npm run dev` | локальная разработка |
| `npm run build` | production-сборка для текущего Vinext/Cloudflare-окружения |
| `npm run build:pages` | статическая сборка GitHub Pages в `out/` |
| `npm test` | production-сборка и smoke-тест |
| `npm run lint` | проверка ESLint |

Код разделён по ответственности:

- `app/page.tsx` — редактор, модель чертежа и связывание интерфейса;
- `app/solver.ts` — независимый численный поиск координат;
- `app/settings-dialog.tsx` — окно настроек;
- `app/help-dialog.tsx` — русская и английская справка;
- `app/i18n.ts` и `app/tool-localization.ts` — локализация;
- `app/interface-icons.tsx` — интерфейсные значки;
- `app/globals.css` — стили.

## Данные

GeoSolver не требует базы данных или серверного API. Черновики сохраняются в
хранилище браузера. Каждая открытая вкладка получает отдельный рабочий чертёж,
поэтому действия в одной вкладке не изменяют другую.

Название проекта можно изменить в шапке. Проект целиком переносится через
JSON-файл через раздел «Настройки»; импорт также поддерживает drag-and-drop.
Там же настраиваются язык интерфейса, тема, точность решателя, единицы углов,
точность отображения, угловые пометки, подсказка активного инструмента и штрихи
равных сторон. Новые файлы содержат название, чертёж, условия, цели, измерения,
точность решателя и положение камеры, при этом старые экспорты также
поддерживаются.

## GitHub Pages

Репозиторий уже подготовлен для статической публикации:

- `next.config.ts` включает `output: "export"` только для Pages-сборки;
- путь проекта автоматически определяется из `GITHUB_REPOSITORY`;
- `.github/workflows/deploy-pages.yml` собирает папку `out/` и публикует её;
- перед публикацией workflow запускает ESLint, production-сборку и smoke-тесты;
- `public/.nojekyll` исключает обработку экспортированных файлов через Jekyll;
- динамические серверные метаданные заменены вычислением во время сборки.

Для публикации:

1. Создайте репозиторий GitHub и отправьте код в ветку `main`.
2. В `Settings → Pages → Build and deployment` выберите источник
   `GitHub Actions`.
3. Запустите workflow вручную или отправьте новый коммит в `main`.

Workflow поддерживает оба варианта адреса:

- пользовательский сайт: `https://owner.github.io/`;
- сайт проекта: `https://owner.github.io/repository/`.

Для сайта проекта префикс `/repository` автоматически добавляется к HTML,
JavaScript, CSS и метаданным. Дополнительная ручная настройка `basePath` не
требуется.

Для локальной проверки статического экспорта:

```bash
npm run build:pages
```

Готовые HTML, CSS и JavaScript появятся в `out/`. Публикация не требует
Cloudflare Worker: решатель продолжает работать полностью на стороне клиента.
