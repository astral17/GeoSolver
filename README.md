# GeoSolver

GeoSolver — клиентский редактор геометрических чертежей и численный решатель
систем ограничений. Построение, история действий, разбор формул и поиск решения
выполняются локально в браузере.

**Текущая версия: 0.2.0**

## Возможности

- Точки; единая секция линейных построений с отрезком, прямой, лучом и
  незамкнутой ломаной.
- Окружности, эллипсы, малые и большие секторы (в том числе с углом больше
  180°), а также круговые сегменты.
- Точки, прикреплённые к отрезку, прямой, лучу, окружности, эллипсу либо
  границе сектора, кругового сегмента и многоугольника.
- Произвольные и правильные многоугольники.
- Произвольные, прямоугольные, равнобедренные и равносторонние треугольники.
- Произвольные четырёхугольники, квадраты, прямоугольники, параллелограммы,
  трапеции и ромбы с готовыми ограничениями.
- Выделение и перемещение группы объектов.
- Измерение длин, углов и площадей по существующим точкам без добавления их в
  цели; для площади доступны автоматическое распознавание фигуры и ручной
  обход выбранных вершин, а перетаскивание пустого поля перемещает камеру.
- Отдельная секция «Задать условие» создаёт по выбранным точкам ограничение
  длины, угла или площади и сразу переводит фокус в поле ввода значения.
- Ограничения длин, углов, площадей, координат и взаимного расположения,
  включая точки пересечения `H = EG ∩ DF`, `line(EG)`, `ray(EG)` и
  `circle(OA)`.
- Пользовательские переменные и формулы, например `a = AB`, `b = 2*a`,
  `a + b = c`.
- Цепочки равенств: `AB = BC = CD`, с автоматическими одинаковыми штрихами
  на равных сторонах и частях объектов вроде `D ∈ AC`, `AD = DC`.
- Адаптивный численный поиск методом наименьших квадратов с настраиваемыми
  допуском `ε` (`1e-6` по умолчанию), числом итераций и временным лимитом;
  при исчерпании лимита показывается ближайшее решение.
- Отмена и повтор действий, переименование точек и непрерывное
  переупорядочивание строк мышью, пальцем или `Alt+↑/↓`; обычные `↑/↓`
  переключают активную строку.
- Адаптивный интерфейс для портретной и альбомной ориентации, с
  полноширинными мобильными разделами, прокручиваемой панелью инструментов и
  масштабированием чертежа жестом двумя пальцами.
- Светлая и тёмная темы с сохранением выбора в браузере.
- Устанавливаемое PWA-приложение с автономным запуском после первого
  успешного открытия; manifest и service worker работают и в подпапке
  GitHub Pages.
- Русский и английский интерфейс с сохранением выбора в браузере.
- Встроенная справка на двух языках, открываемая кнопкой, `F1` или `?`.
- Шесть загружаемых из справки готовых проектов с краткими пояснениями,
  включая задачи с четвертью круга, прямоугольником по диагонали и
  «Опрокинутым квадратом».
- Три сворачиваемые секции левой панели: редактируемый каталог точек и фигур,
  условия и цели.
- В каталоге объектов можно вручную создавать точки и фигуры, временно
  скрывать их, менять порядок перетаскиванием или `Alt+↑/↓` и переходить между
  строками обычными `↑/↓` с сохранением колонки поля, когда это возможно.
  Меню добавления содержит все типы фигур, а точки и фигуры можно удалять
  непосредственно из каталога. Список типов одинаков у всех фигур; при
  несовместимом количестве точек или неверном поле ошибка сразу показывается
  под редактируемым объектом. Стрелки продолжают навигацию между объектами,
  условиями и целями, создавая пустую строку в пустой секции формул.
- Объекты, условия и цели можно объединять в именованные сворачиваемые группы.
  Перетаскивание строки на заголовок развёрнутой группы помещает её внутрь, а
  тонкая линия после группы переносит через её нижнюю границу в обе стороны.
  `Alt+↑/↓` на границе сначала меняет принадлежность строки, не перескакивая
  соседнее условие или цель. У свёрнутых групп зоны переноса нет, и новые
  строки они не принимают. Группы целиком переупорядочиваются
  перетаскиванием за ручку или через `Alt+↑/↓`; мышью группу можно поставить
  непосредственно над или под обычной строкой, а для переноса за открытую
  группу достаточно нижней половины её заголовка. Перестановка происходит
  сразу. Закрытые группы считаются отдельными шагами и не
  перескакиваются. Обычные `↑/↓` заходят в
  редактируемое имя группы между соседними строками. Кнопка выделения фигуры
  или группы выбирает все связанные точки для совместного перемещения на
  чертеже.
- Скрытие фигуры также скрывает связанные с ней штрихи равенства, дуги углов,
  подписи ограничений и результаты измерений.

## Быстрый старт

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

После запуска откройте адрес, показанный в терминале. Для первой задачи:

1. Постройте точки и фигуры.
2. Добавьте условия, например `AB = 5` и `∠ABC = 90°`.
3. Добавьте цель, например `BC`. Необязательный суффикс `= ?` добавится
   автоматически.
4. Нажмите «Решить систему» или `Ctrl+Enter`.

## Синтаксис

Примеры ограничений:

```text
AB = 5
∠ABC = ∠BCA + 10°
S(ABCD) = 12
P(ABCD) = 16
S(circle(AB)) = 25*pi
S(sector(ABC)) = 10
A = (2, -1)
D ∈ line(AB)
AB ⟂ CD
AB ∩ CD = ∅
H = EG ∩ DF
H = line(EG) ∩ circle(OA)
distinct(ABCD)
AB != BC
0 < AB <= 10
x(A) >= 0
```

В целях `P(ABCD)` находит периметр многоугольника. Для окружности, эллипса,
сектора и кругового сегмента используйте `S(circle(AB))`,
`S(ellipse(ABC))`, `S(sector(ABC))`, `S(segment(ABC))`; замена `S` на `P`
возвращает длину соответствующей границы. Эти выражения также можно
использовать в ограничениях и формулах.

Специальные символы можно вводить командами:

```text
\angle  → ∠
\cap    → ∩
\empty  → ∅
\deg    → °
\in     → ∈
\perp   → ⟂
\neq    → ≠
\le     → ≤
\ge     → ≥
```

Полный список команд, инструментов и примеров находится во встроенной справке.

## Горячие клавиши инструментов

Хоткеи определяются физической клавишей и работают независимо от раскладки.
Нажатие клавиши секции открывает её и сразу активирует текущий либо первый
вложенный инструмент. Пока секция открыта, цифры `1`–`9` выбирают её пункты,
поэтому они не используются для открытия секций.

| Клавиша | Секция или инструмент |
| --- | --- |
| `S` | линии |
| `C` | окружности |
| `T` | треугольники |
| `F` | четырёхугольники |
| `G` | многоугольники |
| `E` | задать условие |
| `V` / `B` | перемещение / выделение области |
| `P` / `O` | точка / точка на объекте |
| `D` / `A` / `Q` | измерить длину / угол / площадь |

## Команды проекта

| Команда | Назначение |
| --- | --- |
| `npm run dev` | локальная разработка |
| `npm run build` | production-сборка для текущего Vinext/Cloudflare-окружения |
| `npm run build:pages` | статическая сборка GitHub Pages в `out/` |
| `npm test` | production-сборка и smoke-тест |
| `npm run lint` | проверка ESLint |

Код разделён по ответственности:

- `app/page.tsx` — состояние редактора и связывание модулей;
- `app/domain.ts` — общие типы предметной области;
- `app/tools.ts` — единый каталог инструментов, секций, горячих клавиш,
  локализованных названий и ограничений готовых фигур;
- `app/expressions.ts` — разбор формул, условий и целей;
- `app/geometry.ts` — геометрические вычисления и проекции;
- `app/solver.ts` — независимый численный поиск координат;
- `app/project-state.ts` — начальный проект, импорт и снимки истории;
- `app/examples.ts` — метаданные и JSON-загрузчик готовых проектов;
- `public/examples/` — отдельные проекты-примеры, импортируемые справкой;
- `app/object-editing.ts` и `app/objects-section.tsx` — редактирование и
  представление объектов чертежа;
- `app/editor-groups.tsx` — общая группировка, заголовки и зоны переноса для
  объектов, условий и целей;
- `app/group-reordering.ts` — перенос групп вместе с их содержимым;
- `app/canvas-renderer.ts`, `app/canvas-hit-testing.ts` и
  `app/canvas-interactions.ts` — отрисовка и управление чертежом;
- `app/app-header.tsx`, `app/tool-rail.tsx`, `app/conditions-panel.tsx` и
  `app/solver-panel.tsx` — крупные части рабочего интерфейса;
- `app/settings-dialog.tsx` — окно настроек;
- `app/help-dialog.tsx` — русская и английская справка;
- `app/i18n.ts` — общая локализация;
- `app/interface-icons.tsx` — интерфейсные значки;
- `app/pwa-registration.tsx`, `public/manifest.webmanifest` и `public/sw.js` —
  установка приложения и автономный кэш;
- `app/styles/` — базовые, рабочие и адаптивные стили; `app/globals.css`
  сохраняет их порядок подключения.

## Данные

GeoSolver не требует базы данных или серверного API. Черновики сохраняются в
хранилище браузера. Каждая открытая вкладка получает отдельный рабочий чертёж,
поэтому действия в одной вкладке не изменяют другую.

Название проекта можно изменить в шапке. Проект целиком переносится через
JSON-файл через раздел «Настройки»; импорт также поддерживает drag-and-drop.
Там же настраиваются язык интерфейса, тема, точность решателя, единицы углов,
точность отображения, угловые пометки, подписи ограничений площади, подсказка
активного инструмента и штрихи равных сторон. Новые файлы содержат название,
чертёж, условия, цели, измерения, точность решателя и положение камеры, при
этом старые экспорты также поддерживаются. Если несколько точек совпадают или
находятся очень близко, короткие клики инструментом «Переместить» циклически
переключают выбранную точку; начало перетаскивания сохраняет текущий выбор.

## GitHub Pages

Репозиторий уже подготовлен для статической публикации:

- `next.config.ts` включает `output: "export"` только для Pages-сборки;
- путь проекта автоматически определяется из `GITHUB_REPOSITORY`;
- `.github/workflows/deploy-pages.yml` собирает папку `out/` и публикует её;
- перед публикацией workflow запускает ESLint, production-сборку и smoke-тесты;
- `public/.nojekyll` исключает обработку экспортированных файлов через Jekyll;
- динамические серверные метаданные заменены вычислением во время сборки.
- PWA-манифест использует относительные `start_url` и `scope`, а service
  worker вычисляет адрес относительно манифеста, поэтому установка работает
  как на корневом домене, так и по адресу `/repository/`.

Для публикации:

1. Создайте репозиторий GitHub и отправьте код в ветку `main`.
2. В `Settings → Pages → Build and deployment` выберите источник
   `GitHub Actions`.
3. Запустите workflow вручную или отправьте новый коммит в `main`.

Workflow поддерживает оба варианта адреса:

- пользовательский сайт: `https://owner.github.io/`;
- сайт проекта: `https://owner.github.io/repository/`.

Для сайта проекта префикс `/repository` автоматически добавляется к HTML,
JavaScript, CSS и метаданным. Дополнительная ручная настройка `basePath` не
требуется.

Для локальной проверки статического экспорта:

```bash
npm run build:pages
```

Готовые HTML, CSS и JavaScript появятся в `out/`. Публикация не требует
Cloudflare Worker: решатель продолжает работать полностью на стороне клиента.
После публикации откройте сайт по HTTPS хотя бы один раз. В поддерживаемом
браузере появится команда «Установить приложение»; после загрузки ресурсов
редактор сможет запускаться автономно. На iOS используется команда
«Поделиться → На экран Домой».

## Релиз 0.2.0

Версия `0.2.0` фиксирует второй клиентский релиз. По сравнению с `0.1.0`
добавлены и расширены:

- эллипсы, секторы, круговые сегменты, ломаные и готовые четырёхугольники;
- условия неравенств, пересечений, координат, площадей и периметров;
- настраиваемый численный поиск и дополнительные регрессионные примеры;
- каталог объектов, именованные группы и непрерывное переупорядочивание;
- двуязычная справка с импортируемыми JSON-примерами;
- полноценная мобильная компоновка, жест масштабирования и PWA-режим;
- статическая публикация из подпапки GitHub Pages.

Перед созданием тега `v0.2.0` рекомендуется выполнить:

```bash
npm ci
npm run lint
npm test
npm run build:pages
```

После успешной проверки можно создать тег и GitHub Release. Сам сайт
публикуется workflow при отправке релизного коммита в ветку `main`.
